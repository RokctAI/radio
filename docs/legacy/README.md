# Pre-slice originals (reference only - nothing here compiles)

When this repo became a composed app shell (`lib/` is now generated by
compose on every build; see the root `.gitignore`), every `lib/` file whose
code was **ported into radio_sdk** was deleted here - the SDK copy on
RokctAI/agent is the living version. The files under `docs/legacy/lib/`
are the ones that were **not** ported anywhere: they are preserved verbatim
so no feature code or per-app value exists only in git history.

Disposition:

| File(s) | Why kept | Where the concern lives now |
|---|---|---|
| `lib/app_constants.dart` | Record of every per-app value (stream URL, name, motto, social URLs, min-version, OneSignal id, ad ids) | dart-defines read by radio_sdk's installed templates (`RADIO_STREAM_URL`, `RADIO_STATION_NAME`, `RADIO_*_URL`), `tour/app.tour.yaml` (branding), comms_sdk (push), base remote config |
| `lib/main.dart` | Record of the hand-written host wiring (StationsSourceFacade registration, boot order) | generated by compose from the SDK manifests |
| `lib/application/ads/*`, `lib/infrastructure/services/interstitial_ad.dart`, `open_ad_manager.dart` | Ad mediation code, not ported (promotions_sdk territory; this station ships with ads off and Google TEST ids) | `promotions_sdk` (disabled in composer.json) + radio_sdk's `RadioInterstitialGate` seam |
| `lib/application/theme/*` | ThemeMode plumbing | base_sdk theme system |
| `lib/presentation/component/no_internet_dialog.dart` | App-brand no-connection dialog (uses `noInternet.svg`) | base_sdk's `NoConnectionDialog`, which radio_sdk's home page now shows |
| `lib/presentation/pages/splash/splash_page.dart` | Min-app-version gate (`Constant.minAppVersion` -> webview) - a feature with no SDK home yet (flagged follow-up) | base_sdk splash page (without the gate) |
| `lib/presentation/pages/webview/webview_page.dart` | Generic webview page | base territory |
| `lib/presentation/styles/app_style.dart`, `color_utils.dart`, `lib/presentation/theme/theme.dart` | Record of the app's brand palette (`radioBgDarkColor` 0xFF101016 was the one injected value) and theme helpers; `RadioStyle` moved to radio_sdk's `radio_style.dart` template | the compose-installed theme shim's `applyAppBrandColors()` |
| `lib/utils/app_pref.dart`, `language.dart` | SharedPreferences + string tables | base_sdk LocalStorage / tr_keys |

Deleted outright (already living in radio_sdk on RokctAI/agent -
`templates/pages/radio/` and `lib/src/common/`): the radio player page,
home drawer, timer page, the five player widgets, blurred background,
`ConstantStationsSource` (+ its test), `AppBackground`, `AppLayout`
(as `radio_layout.dart`), `duration_extension` (as `duration_format.dart`).
Also deleted: `app_router.dart` / `app_router.gr.dart` and the one-line
theme shim - pure generated artifacts the composer recreates.
