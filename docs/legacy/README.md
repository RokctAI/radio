# Pre-slice originals (reference only - nothing here compiles)

When this repo became a composed app shell (`lib/` is now generated by
compose on every build; see the root `.gitignore`), every `lib/` file whose
code was **ported into radio_sdk** was deleted here - the SDK copy on
RokctAI/agent is the living version. The files under `docs/legacy/lib/`
are the ones that were **not** ported anywhere: they are preserved
unchanged (apart from the fleet MIT license header CI requires on `.dart`
files) so no feature code or per-app value exists only in git history.

## Disposition of the kept files

- `lib/app_constants.dart` - record of every per-app value (stream URL,
  name, motto, social URLs, min-version, OneSignal id, ad ids). The
  concerns now travel as dart-defines read by radio_sdk's installed
  templates (`RADIO_STREAM_URL`, `RADIO_STATION_NAME`, `RADIO_*_URL`),
  as `tour/app.tour.yaml` branding, and via comms_sdk / base remote
  config.
- `lib/main.dart` - record of the hand-written host wiring
  (StationsSourceFacade registration, boot order). Compose now generates
  main from the SDK manifests.
- `lib/application/ads/*`, `lib/infrastructure/services/
  interstitial_ad.dart`, `open_ad_manager.dart` - ad mediation code, not
  ported (promotions territory; this station ships with ads off and
  Google TEST ids). The seam is promotions_sdk (disabled in
  composer.json) plus radio_sdk's `RadioInterstitialGate`.
- `lib/application/theme/*` - ThemeMode plumbing; base_sdk theme system
  owns this now.
- `lib/presentation/component/no_internet_dialog.dart` - app-brand
  no-connection dialog (uses `noInternet.svg`); radio_sdk's home page now
  shows base_sdk's `NoConnectionDialog` instead.
- `lib/presentation/pages/splash/splash_page.dart` - min-app-version gate
  (`Constant.minAppVersion` -> webview), a feature with no SDK home yet
  (flagged follow-up). base_sdk's splash page ships without the gate.
- `lib/presentation/pages/webview/webview_page.dart` - generic webview
  page; base territory.
- `lib/presentation/styles/app_style.dart`, `color_utils.dart`,
  `lib/presentation/theme/theme.dart` - record of the app's brand palette
  (`radioBgDarkColor` 0xFF101016 was the one injected value) and theme
  helpers; `RadioStyle` moved to radio_sdk's `radio_style.dart` template.
  The compose-installed theme shim's `applyAppBrandColors()` is the new
  home for the injection.
- `lib/utils/app_pref.dart`, `language.dart` - SharedPreferences wrapper
  and string tables; base_sdk LocalStorage / tr_keys territory.

## Deleted outright

Already living in radio_sdk on RokctAI/agent (`templates/pages/radio/`
and `lib/src/common/`): the radio player page, home drawer, timer page,
the five player widgets, blurred background, `ConstantStationsSource`
(plus its test), `AppBackground`, `AppLayout` (as `radio_layout.dart`),
and `duration_extension` (as `duration_format.dart`).

Also deleted: `app_router.dart` / `app_router.gr.dart` and the one-line
theme shim - pure generated artifacts the composer recreates.
